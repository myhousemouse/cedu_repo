# Planning workspace

These documents are the shared memory for planning across Codex sessions.

## Reading order

1. [Current state](current-state.md) — latest context and next action
2. [Product brief](product-brief.md) — problem, audience, and product direction
3. [Requirements](requirements.md) — scoped product requirements
4. [User flows](user-flows.md) — intended user journeys
5. [Open questions](open-questions.md) — unresolved decisions
6. [Decision records](decisions/README.md) — durable decisions and rationale
7. [Research](research/README.md) — source-backed investigation notes

The [source map](research/source-map.md) lists the official services and the
local historical reference vault available to future sessions.

## Document conventions

- `Confirmed`: explicitly agreed with the user.
- `Assumption`: a working hypothesis that still needs validation.
- `Proposal`: a suggested direction awaiting a decision.
- `Open question`: an unresolved choice or missing fact.

Update canonical documents in place. Use dated decision records only for
choices whose rationale should remain visible over time.
