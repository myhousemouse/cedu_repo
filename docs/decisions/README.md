# Decision records

Create a record for a durable product or technical decision whose rationale
should remain available in later sessions.

Use filenames in the form `YYYY-MM-DD-short-title.md`.

## Template

```md
# Decision: Title

- Date: YYYY-MM-DD
- Status: Proposed | Accepted | Superseded

## Context

What prompted the decision?

## Decision

What was decided?

## Rationale

Why was this option chosen?

## Consequences

What becomes easier, harder, or constrained?
```
